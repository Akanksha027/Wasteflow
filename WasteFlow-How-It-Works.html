WasteFlow Operations Guide

How WasteFlow Works

Simple explanation of the whole system — who does what, how drivers are created, and how the website and phone app stay connected.

1. Big picture (one system, two apps)

WasteFlow is a waste-collection tracking system. There is one shared database and two apps that use it.

System connection map
WasteFlow ERP Website for office staff
wasteflow-drab.vercel.app
Shared Database Supabase (cloud)
Same data for everyone
Driver App Phone app for drivers
Expo / mobile

Office plans work on the website → Drivers do work on the phone → Both see the same live data

2. The four roles

Role Where they work What they do
Admin ERP website Full control — staff, routes, vehicles, settings, deletes
Supervisor ERP website Daily operations — routes, board, tracking, assignments
Driver Driver phone app Start trips, collect stops, GPS, photos, finish trips
Field Worker ERP (scanner / field) Scan QR codes, enter waste quantities on site
Important: The phone Driver App only allows accounts with role driver. Admins and supervisors must use the ERP website.

4. How to make a new driver (exact flow)

Two pieces must connect: a login and an employee profile.

Create a driver — step by step
1
Create a login
In Supabase Auth (or Google sign-in), create email + password for the person. Example: ram.driver@city.gov / a temporary password.
2
Open ERP → Employees → Add employee
Fill name, Employee ID (EMP-00x), set Role = Driver, assign a Route and Vehicle.
3
Link auth account (email)
Type the same email as their login. This attaches the employee to that login so the Driver App can load their route and start trips.
4
Driver opens the phone app
They sign in with that email + password (or Google). App checks: role = driver + employee linked → shows their assigned work.
What “Link auth account” means: Employee record = job profile (route, vehicle). Auth account = ability to log in. The link field joins them. Without it, login works but the app says “No employee profile — ask admin to link you.”

9. One-sentence summary

Admin/Supervisor plan people, routes, and today’s work in the ERP website; Drivers carry out that work in the phone app; everyone reads and writes the same database so the office sees fieldwork in real time.
